# MSH - 股權分散表大股東籌碼分析系統

台灣股市大股東籌碼追蹤與分析平台，整合 TDCC 集保股權分散表數據，提供智能起漲標的篩選。

## 系統架構

- **資料來源**: TDCC 集保股權分散表 + TWSE 財務數據
- **後端**: Cloudflare Workers + D1 資料庫
- **前端**: Next.js 部署於 Cloudflare Pages
- **自動化**: GitHub Actions 每週六 16:00 自動更新

## 核心功能

- 股權分散表週報自動爬取
- 大股東籌碼集中度分析
- 起漲潛力標的自動篩選（上市/上櫃各 10-20 檔）
- 12週籌碼變化熱力圖
- 股東人數背離警示

## 「起漲潛力」篩選邏輯與評分機制

原始碼位置：`frontend/src/app/top-changes/page.tsx`

### 篩選邏輯（`shouldInclude`）

進入候選名單前，會先排除以下標的：

- 無產業別（`industry` 為空）
- ETF
- 存託憑證
- 創新板股票
- 已下市
- 特別股（以證券代碼格式判斷：4 位數字 + 英文字母，例如權證/特別股常見代碼格式）

不再依股票名稱結尾字元（例如「創」「特」）做排除。舊版邏輯曾經只要名稱結尾是這些字就一律剔除，這會誤刪名稱剛好帶有這些字、但實際上是一般上市/上櫃股的公司；目前一律以「產業別」與「證券代碼格式」為準。

### 基礎籌碼分數（`scoreStock`）

分數只反映大股東籌碼集中度變化，不含股價或技術面因素，由四個部分加總：

1. 12 週大股東持股比累計變動 × 2，最高 30 分
2. 連續增持週數（由最新一週往回算，連續為正的週數）× 5 分，無上限
3. 最新一週變動 × 3，僅正值計分，最高 20 分
4. 最新大股東持股比 × 0.2，最高 15 分

同時要求「累計變動 > 0」且「最新持股比 > 10%」才會進入候選名單，取分數最高的前 20 檔。

### 技術指標共振加分（選用，`calcTechnicalBonus`）

預設關閉，使用者可在「起漲潛力」面板勾選「技術指標共振」啟用。啟用後，僅對籌碼分數前 60 名候選股額外呼叫 `/api/technical/:code`（日成交量 / KD / MACD，資料來源 FinMind）計算以下加分，三項各 +10 分，最高 +30 分，計入總分後重新排序取前 20 檔：

- **KD 黃金交叉**：前一交易日 K ≤ D、當日 K > D，且當日 K 值 ≤ 使用者設定門檻（預設 30，可調整，例如 20）
- **MACD 柱狀圖翻正**：前一交易日柱狀圖 ≤ 0、當日 > 0
- **成交量放大**：當日成交量 ÷ 過去 5 個交易日均量 ≥ 使用者設定倍數（預設 1.5，可調整，例如 2）

若某檔股票抓不到技術資料（例如尚未快取、API 額度限制），該項加分以 0 分計，不影響基礎籌碼分數的排序結果。頁面上有「評分說明」按鈕可展開查看目前門檻與完整規則說明。
