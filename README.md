# MSH - 股權分散表大股東籌碼分析系統

台灣股市大股東籌碼追蹤與分析平台，整合 TDCC 集保股權分散表數據，提供智能起漲標的篩選。

## 系統架構

- **資料來源**: TDCC 集保股權分散表 + TWSE 財務數據
- **後端**: Cloudflare Workers + D1 資料庫  
- **前端**: Next.js 部署於 Cloudflare Pages
- **自動化**: GitHub Actions 每週六 16:00 自動更新

## 核心功能

- 股權分散表週報自動爬取
- 大股東籌碼集中度分析
- 起漲潛力標的自動篩選（上市/上櫃各 10-20 檔）
- 12週籌碼變化熱力圖
- 股東人數背離警示
